# webMethods Flow Pilot — Sample Package

This repository contains webMethods Integration Server Flow Services generated and curated as part of the **IBM Bob Flow Pilot** skill validation.

The package is designed to be imported into an **IBM webMethods Hybrid Integration (IWHI)** instance via the Packages → Git pull mechanism.

---

## What is Flow Pilot?

Flow Pilot is a Bob skill that generates functional webMethods Integration Server Flow Services from natural language descriptions. It produces valid Flow XML artifacts ready to deploy to Integration Server without manual coding.

---

## Services

### `exchange` namespace

| Service | Description |
|---------|-------------|
| `GetJokeAsXML` | Calls the public [Official Joke API](https://official-joke-api.appspot.com/random_joke), parses the JSON response, and returns the result as an XML string. Generated by Flow Pilot as a proof-of-concept. |
| `GetExchangeRates` | Retrieves foreign exchange rates from the [Frankfurter API](https://api.frankfurter.dev). Accepts an optional base currency and target currency. |

### `Deposits` namespace

| Service | Description |
|---------|-------------|
| `CompoundInterestCalculator` | Calculates the growth trajectory of a savings account applying compound interest over a configurable horizon. |

### `Cards` namespace

| Service | Description |
|---------|-------------|
| `CreditCardRevolvingDebtPayoffOptimizer` | Optimizes the payoff strategy for revolving credit card debt. |

### `Loans` namespace

| Service | Description |
|---------|-------------|
| `AmortizationCalculator` | Generates a full amortization schedule for a loan. |
| `CalculateFixedMonthlyPrincipalAndInterestPayment` | Calculates the fixed monthly payment for a loan given principal, rate, and term. |
| `CalculateMonthlyInterestRate` | Derives the monthly interest rate from an annual rate. |

### `Risk` namespace

| Service | Description |
|---------|-------------|
| `DebtServiceCoverageRatioCalculator` | Calculates the Debt Service Coverage Ratio (DSCR) for risk assessment. |

### `orders` namespace

| Service | Description |
|---------|-------------|
| `processOrder` | Processes a shopping cart order applying business rules and inventory checks. |
| `applyDiscount` | Applies a discount to an order based on configurable rules. |

## How to use

1. In your IWHI instance, go to **Integrations → Packages**
2. Add this repository as a Git source using your GitHub credentials
3. Select branch `main` and click **Pull**
4. Reload the package
5. Open any Flow Service from the list and click **Run**
